TENSOR vs PARAMETER
  - A tensor is not a parameter. torch.Tensor is the base class; torch.nn.Parameter is a subclass that additionally requires_grad=True by default and is registered in a module's parameter list.
  - The tracked object is exactly one trainable scalar element. The gradient, the activations, the prediction, the loss and the optimizer state are five different tensors, and none of them is the parameter.
  - parameter.grad is a separate tensor that autograd allocates and writes; it is not a view of the parameter and does not alias it.
  - Optimizer state (exp_avg, exp_avg_sq, momentum_buffer) is memory about the parameter's update history. It is not a second copy of the parameter and does not move when the parameter moves.
